# TextScope – Text Data Search and Summarization Tool

TextScope is a simple web-based tool we developed for our Scripting Workshop project. It helps users search, clean, and analyze text files using shell scripting commands like `grep`, `awk`, and `sed`.

The project includes features like pattern searching, word frequency analysis, sentence length analysis, text cleaning, stop-word removal, and report generation.

We also built a dark-themed dashboard to make the tool easier to use.

### Technologies Used
- Bash, grep, awk, sed
- Python
- HTML, CSS, JavaScript

### How to Run

1. Download or clone the repository.
2. Open Terminal and navigate to the project folder.
3. Run the following commands:

```bash
chmod +x *.sh
./start_prototype.sh
```

4. Open **http://localhost:8000** in your browser.

The tool runs locally on macOS and Linux.
